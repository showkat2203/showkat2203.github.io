Drop an official logo here as `<institution-key>.svg` — for example `aws.svg` —
and the site uses it in place of the typographic monogram. The keys are the
top-level keys in `src/content/institutions.yaml`.

Use a single-colour SVG: the tile renders monochrome so that every institution
sits in one visual system rather than looking like a row of scraped brand
assets. Only add marks you are licensed to use.
